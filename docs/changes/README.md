# Change reports

One folder per feature-sized change: `NNNN-short-slug/`. Each holds the full output of the roles described in [CONTRIBUTING.md](../../CONTRIBUTING.md#change-reports):

- `plan.md`: Planner (scope, design, data model and diagram impact, test plan)
- `qa.md`: QA (approach, edge cases, defects sent back, anything not verified)
- `review.md`: Reviewer (loop-backs, accepted trade-offs)
- `security.md`: Security (fixed findings, accepted risks, follow-ups)
